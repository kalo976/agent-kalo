# Équipe com Meubles & Déco

L'équipe communication de Meubles & Déco et de Dagonii (Mayotte) : les mêmes 20 agents que l'équipe Kalo, réécrits pour l'ameublement, avec **Maxime** (`md-cerveau`) au centre à la place de David. Les agents Kalo ne sont pas modifiés.

| Île | Agents |
| --- | --- |
| Centre | Maxime (`md-cerveau`) |
| Pilotage | Chimène (`md-chef-com`), Chanisse (`md-calendrier`), Zayeb (`md-operations-commerciales`) |
| Marque | Gamil (`md-marque`), Ousséni (`md-critique`) |
| Écriture | Zaïna (`md-post-facebook`), Anli (`md-whatsapp-sms`), Thomas (`md-fiches-produits`) |
| Création | Sahel (`md-visuel-produit`), Kamil (`md-video-courte`) |
| Arène | Roukia (`md-challenger-affiches`), Bacar (`md-challenger-videos`), Faïza (`md-challenger-posts`), Fahardine (`md-challenger-operations`), Mariama (`md-challenger-calendrier`) |
| Clients | Charza (`md-community-manager`), Nasser (`md-avis-clients`) |
| Analyse | Nahim (`md-statistiques`), Chloé (`md-veille-concurrence`) |

- Agents : `meubles-deco/skills/md-*`
- Cerveau (coffre Obsidian) : `meubles-deco/cerveau/`, à lire avant toute tâche
- Livrables : `meubles-deco/journal/AAAA-MM-JJ/`

Toute demande passe par Chimène. Chaque livrable passe par Ousséni, puis par la direction. Rien n'est publié sans validation.

## Installer
- **claude.ai** : importer le fichier `equipe-meubles-deco.plugin` (fabriqué par `bash meubles-deco/paquet.sh`).
- **Claude Code** : copier `meubles-deco/skills/md-*` dans `~/.claude/skills/`.
